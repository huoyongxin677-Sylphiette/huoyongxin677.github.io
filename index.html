      云端同步

      改动会自动存进这台设备的浏览器，刷新、关掉再打开都还在。如果填了 GitHub Token，还会自动同步到你的 GitHub 仓库，换一台设备（手机/别的电脑）打开也是最新记录。

      读取云端不需要 Token（仓库是公开的）。写入云端需要一次 Token，它只存在这台设备的浏览器里，不会写进公开的网页文件。

      生成方法：GitHub 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access 只勾这一个仓库 → Permissions → Contents 选 Read and write → 生成后复制 github_pat_…。
